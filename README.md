# 怒喵电量与多屏任务栏 · 1.0.0

Windows 原生便携工具，显示 AM INFINITY 鼠标和 Dongle 备用电池的电量，并管理每块屏幕的任务栏。无需运行 AM_Master，无需安装第三方运行环境，图片和图标均已内置。

## 启动与升级

从 [GitHub Releases](https://github.com/awesomehy/AMBattery/releases/latest) 下载 `AMBattery-1.0.0-win-x64.zip`，解压到可写目录，双击 `AMBattery.exe`。新版启动时会请求旧版正常退出、等待任务栏恢复，再接管显示。设置保存在程序旁的 `data/settings.json`；新目录没有设置文件时，会自动迁移正在运行的旧版设置。

请将 `AMBattery.exe` 和 `AMBattery.Recovery.exe` 放在同一目录。后者负责在主程序异常退出时恢复任务栏。便携压缩包已包含两个程序。

右键电量组件或托盘图标可打开设置、查看详情和退出。关闭设置或详情窗口会收起界面，程序继续显示电量。

## 外观与使用

- 提供“简约 · 明亮”和“简约 · 深色”，点击即切换并保存。设置、详情浮窗、下拉菜单和托盘菜单同步变色。
- 设置页和详情浮窗加入 Angry Miao、NO WIRE BY ANGRYMIAO 品牌图，取自本机 AM_Master 的原始资源；深色使用白色标志，明亮使用深色标志，图片按需载入并缓存。
- 开关采用圆角轨道和滑动圆点；按钮、字体、间距、下拉选项和偏移调节统一样式。开关可用空格切换，下拉选项和偏移可用方向键调整。
- 任务栏采用选定的 A 款“圆润极简”鼠标图案（Lucide Mouse），搭配鼠标电量圆环；自动适配系统任务栏明暗颜色，按屏幕缩放比例直接绘制矢量轮廓。点击后显示鼠标、Dongle 电量、充电状态和更新时间。
- 电量浮窗不显示关闭按钮；点击桌面空白或其他窗口时自动收起，也可按 Esc 收起。
- 浮窗中的 Dongle 采用 AM_Master 产品原图里的圆形充电仓图片，保留透明背景与原色。构建时缩小为 128 像素，首次显示时载入并缓存，无需运行时读取 AM_Master 文件。
- 圆环 ≥60% 为绿色，30%～59% 为黄色，<30% 为红色。
- 默认主屏自动隐藏，副屏常显，电量优先位于副屏时钟左侧。可以分别选择任务栏模式、组件所在屏幕、栏内位置和向内偏移。
- 在设置中点击“应用设置”或“完成”保存功能设置；主题点击后立即保存。首次启动不会自动接管任务栏。

## 性能优化

- 电量自动读取间隔从 15 秒改为 30 秒；详情中的“刷新”可立即读取。
- 缓存接收器路径和任务栏句柄，设备异常时重新发现，屏幕变化时刷新显示缓存。
- 电量、尺寸、位置和系统主题没有变化时，复用任务栏画面，避免重复绘制和重复设置窗口位置。隐藏的详情不会随读数刷新重绘，详情窗口首次点击时才创建。
- 仅启用自动隐藏的屏幕需要较快地检测底边鼠标位置；其他情况降低定时检查频率。任务栏工作区域仅在不一致时写入。
- 开关动画仅在交互时短暂运行，结束后停止计时器。没有持续运行的视觉动画。
- 官网鼠标原图在构建时裁剪，运行时直接载入透明内容，避免启动时解码整张 1500×800 原图和扫描像素。
- 独立恢复程序等待 Windows 进程退出信号；正常等待时不载入界面和 JSON 恢复依赖。8 秒空闲采样中，恢复程序专用内存约 8.95 MB、工作集约 12.64 MB，CPU 时间增量为 0 ms。旧版恢复进程实测专用内存约 18.5 MB。以上只针对恢复进程，不代表新版主程序总占用。
- 未使用强制垃圾回收或清空工作集来降低任务管理器上的数字。

## 通知

鼠标进入 <30% 时发送一次 Windows 通知；回到 ≥30% 后允许下次低电量提醒。启动时已经低于 30% 也会提醒一次。通知被系统关闭或全屏状态阻止时，保留稍后提醒机会。

“测试通知”会检查系统允许状态，等待 Windows 的显示回执；如果系统未确认，会给出明确提示。“通知设置”打开 Windows 对应页面，可检查系统通知总开关和应用通知权限。工具不会修改云推送策略或服务。

## 恢复与设备说明

“恢复系统任务栏”和正常退出会恢复接管前的任务栏样式、系统自动隐藏设置和工作区域。异常恢复记录位于 `data/taskbar-recovery.json`，恢复程序只读取自身目录下、属于对应主进程的记录。

每屏自动隐藏通过 Explorer 任务栏窗口样式实现。当前编译目标为 Windows 11 x64、.NET Framework 4.x，不同 Windows 版本可能需要适配。现有检查覆盖离屏绘制和功能回归，无法替代不同 Windows 版本、显示器组合和长期运行的现场验证。

为避免同时访问接收器，检测到 AM_Master 运行时暂停读取，退出 AM_Master 后自动恢复。Dongle 状态沿用怒喵官方驱动的判定：1%～99% 为充电中，100% 为已充满，0 显示未检测到电池；固件未提供独立的完整充电标志。鼠标状态直接读取 D6 响应。

## 构建与检查

运行 `build.ps1`，使用 Windows 自带的 .NET Framework C# 编译器，输出 `build/AMBattery.exe` 和 `build/AMBattery.Recovery.exe`。无需下载包。

运行 `test.ps1` 检查电量解析、30% / 60% 分界、提醒去重与重试、窗口关闭复用、主题保存、控件键盘行为、布局边界和恢复记录兼容性。检查只建立隐藏窗口，不显示或操作桌面界面。原生渲染预览位于 `build/ui-preview/`。

运行 `release.ps1` 会重新构建、运行上述检查，并在 `dist/` 生成便携 ZIP 和 `SHA256SUMS.txt`。压缩包包含两个程序、使用说明和素材许可；个人设置、日志、研究缓存和旧版构建不会打包。使用 PowerShell 7，或在 Windows PowerShell 中以 `powershell -ExecutionPolicy Bypass -File .\release.ps1` 运行。

电量协议依据[怒喵官方网页驱动](https://ammaster.angrymiao.com/mouse)。鼠标图片来自[怒喵官网资源](https://cdn-www.angrymiao.com/products/products_am_infinity_mouse.png)，原图保存在 `assets/am-infinity-mouse.png`。每屏任务栏处理参考 MIT 许可项目 [Per-Monitor Taskbar](https://github.com/nikoleinonen/per-monitor-taskbar) 的窗口样式思路，以 C# 独立实现，未捆绑其可执行文件。

任务栏矢量图案取自 [Lucide Mouse](https://lucide.dev/icons/mouse)，原 SVG 保存在 `assets/icon-candidates/a.svg`，按 ISC 许可使用；发布包包含对应的 `lucide-LICENSE.txt`。
